⚙️ Ollama 設定

① Ollamaをインストール

https://ollama.com からダウンロード

② モデルをダウンロード（どちらか）

# テキスト用 (2GB)
ollama pull llama3.2

# 画像解析用 (4.7GB)
ollama pull llava

# ※ 1つで両方対応 (8GB)
ollama pull llama3.2-vision

③ Ollamaを起動

ollama serve

起動後、このページをリロードしてください。

使用するモデルを選択してください。

※ 画像解析には llava / llava:13b / moondream / llama3.2-vision が必要です
